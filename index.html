기능 소개

이미지에서 PDF 만들기

여러 장의 JPG, PNG, WebP 이미지를 선택하면 각 이미지를 한 페이지로 배치한 PDF 파일을 생성합니다. 영수증, 스캔 이미지, 과제 제출 자료처럼 이미지 파일을 하나의 문서로 정리해야 할 때 유용합니다.

PDF 페이지 이미지 저장

PDF를 업로드하면 페이지를 순서대로 렌더링하고 PNG 이미지로 내려받을 수 있습니다. 썸네일 제작, 문서 미리보기, 일부 페이지 공유처럼 PDF 내용을 이미지로 활용해야 하는 상황에 맞춰 설계했습니다.

정적 웹 기반 구조

이 사이트는 HTML, CSS, JavaScript로 구성되어 Cloudflare Pages 같은 정적 호스팅 환경에 배포하기 쉽습니다. 변환 작업은 클라이언트에서 수행되므로 별도 서버, 데이터베이스, 로그인 시스템이 필요하지 않습니다.

확장 가능한 메뉴

우측 하단 시작 버튼과 창 내부 탭 구조를 통해 앞으로 압축, 병합, 분할, 워터마크 같은 추가 도구를 자연스럽게 연결할 수 있습니다. 기능별 설정과 안내 문구를 독립적으로 관리하기 좋게 구성했습니다.
